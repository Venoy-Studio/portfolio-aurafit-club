# AuraFit Club — Website Landing Page Clone

Clone fiel e otimizado da landing page da **AuraFit**, desenvolvido com tecnologias modernas de alto desempenho: **React 19**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, **Lenis (smooth scroll)** e shaders interativos em **WebGL**.

## ✨ Destaques da Implementação

- **100% Livre de Marcas d'Água:** Removida qualquer marca d'água ou badge de terceiros (Netlify).
- **Contatos Fictícios Estruturados:** Endereço na Av. Paulista, horários, WhatsApp formatado com link direto, telefone fixo e e-mail institucional fictícios.
- **Fundo Interativo WebGL:** Dot matrix interativo reativo ao movimento do mouse/touch com ondulação magnética e brilho verde neon (#C6FF00).
- **Hero com Vídeo Otimizado:** Vídeo em loop de alta definição com fallback automático para poster, controles de áudio (Mudo/Som) e modal para teste de vídeos customizados.
- **Navegação & Smooth Scroll:** Integração suave com Lenis, IntersectionObserver para destaque dinâmico da seção ativa e drawer responsivo para mobile.
- **Bento Grid de Diferenciais:** Cards imersivos com efeitos de zoom, microinterações e gradientes profundos.
- **Carrossel de Casos de Sucesso:** Navegação por botões e arraste horizontal suave (drag & scroll).
- **Planos e Matrícula Interativa:** Tabela de planos com modal de inscrição multi-etapas e validação de dados.

## 🚀 Como Executar Localmente

### 1. Instalar as dependências
```bash
npm install
```

### 2. Iniciar o servidor de desenvolvimento
```bash
npm run dev
```

### 3. Compilar para produção
```bash
npm run build
```

### 4. Visualizar o build de produção
```bash
npm run preview
```
